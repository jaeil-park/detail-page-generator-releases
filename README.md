# 상세페이지 자동생성기 — 다운로드

십이월마켓 상세페이지 자동생성기 배포 파일 저장소입니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/jaeil-park/detail-page-generator-releases/releases/latest)**

`DetailPageGenerator.exe`를 받아서 바로 실행하면 됩니다 (설치 과정 없음).

## 사용법

실행 파일과 함께 첨부된 `manual.html`(사용설명서)을 더블클릭하면 브라우저로 바로 열립니다.

## 이용 안내

이 프로그램은 **구독형 서비스**로 제공되며, 버전마다 지정된 사용기간이 있습니다.
사용기간이 만료되면 프로그램 실행이 제한되며, 실행 시 남은 기간(D-day)이 안내됩니다.
연장 및 갱신은 담당자에게 문의해주세요.

## 시스템 요구사항

Windows 10 / 11 (64bit)
