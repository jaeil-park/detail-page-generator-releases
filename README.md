# 상세페이지 자동생성기 — 다운로드

십이월마켓 상세페이지 자동생성기 배포 파일 저장소입니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/jaeil-park/detail-page-generator-releases/releases/latest)**

`DetailPageGenerator.exe`를 받아서 바로 실행하면 됩니다 (설치 과정 없음).

## 사용법

실행 파일과 함께 첨부된 `사용설명서.html`을 더블클릭하면 브라우저로 바로 열립니다.

## 시스템 요구사항

Windows 10 / 11 (64bit)
